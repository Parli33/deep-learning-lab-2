# Лабораторная работа №2. Обучение нейронной сети с нуля

Вариант **5**: Fashion-MNIST, сеть **784 → 256 → 10**, **Sigmoid**,
начальный learning rate **0.05**. Seed: **42**. Обучение на **CPU**,
batch_size **64**, разбиение **48 000 train / 12 000 val**.

ФИО: Пархомец Илья Русланович
Номер зачётной книжки: 230355

Вся работа находится в `lab2_5_Parkhomets.ipynb`: подготовка данных, модель,
ручной SGD, сравнение с PyTorch, подбор lr, регуляризация, early stopping,
метрики, графики, проверки и выводы. Отдельные Python-скрипты не нужны.

## Окружение

- Python **3.12.12**.
- torch **2.14.0+cpu**, torchvision **0.29.0+cpu**.
- numpy **2.5.3**, matplotlib **3.11.2**.
- JupyterLab **4.6.4** для запуска ноутбука.

Версии закреплены в `requirements.txt`.

## Запуск через venv и pip

Сначала установите Python 3.12.12. Проверьте версию перед созданием окружения:

```bash
python3.12 --version
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m jupyterlab lab2_5_Parkhomets.ipynb
```

Команда проверки должна вывести `Python 3.12.12`.
На Windows окружение активируется командой `.venv\Scripts\activate`.

## Результаты

Лучший learning rate — 0.5. Базовая сеть без регуляризации получила
accuracy 88,93% и macro-F1 0,88953 на валидации.

Dropout и weight decay не улучшили результат. Early stopping остановил
обучение на 23-й эпохе и восстановил веса 20-й эпохи:
val loss составил 0,31147 против 0,31836 после всех 25 эпох.

Ручной SGD и torch.optim.SGD дали практически одинаковые результаты.
Подробные таблицы, графики и выводы находятся в ноутбуке.
